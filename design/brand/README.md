# Pleiades 标志使用规范

采用已确认的淡蓝软雕塑字标与短 `p` 字尾。正式资产以本目录为准；`../logo-concepts/` 保存历史探索稿，不作为后续制作来源。

## 选择文件

| 场景 | 文件 |
| --- | --- |
| 官网页头、文档标题，优先使用 | [英文主字标](pleiades-wordmark.svg) |
| 图形在左、名称在右 | [横排组合](pleiades-horizontal.svg) |
| 纵向空间、标牌 | [竖排组合](pleiades-stacked.svg) |
| 独立图形、较大头像 | [标准图形](pleiades-symbol.svg) |
| 16–32 px 小图形 | [小尺寸图形](pleiades-symbol-small.svg)；浏览器优先使用 [深蓝底 favicon](web/favicon.svg) |
| 深色背景、单色印刷 | `exports/<wordmark|horizontal|stacked|symbol>/` 内的黑色及反白 SVG |
| 办公文档、无需矢量的屏幕素材 | 上述导出目录中的 1024 px 宽透明 PNG |
| 头像、应用图标 | [圆形裁切安全图形](web/pleiades-square.svg)、[应用图标](web/pleiades-app-icon.svg)；对应 PNG 在 `exports/social/` |
| Apple Touch、192/512 图标及 ICO | `web/`；生产使用的副本在 `../../public/` |

使用 SVG 保持缩放清晰。主字标中的文字全部为自绘路径，无第三方字体依赖；不要用普通字体重新输入品牌名称来代替主稿。

## 颜色与背景

| 颜色 | HEX | RGB | 近似 CMYK（%） |
| --- | --- | --- | --- |
| 淡天蓝，标志主色 | `#86C6EF` | 134 / 198 / 239 | 44 / 17 / 0 / 6 |
| 深蓝，图标衬底和辅助文字 | `#17374E` | 23 / 55 / 78 | 71 / 29 / 0 / 69 |
| 黑色，单色使用 | `#000000` | 0 / 0 / 0 | 0 / 0 / 0 / 100 |
| 白色，反白使用 | `#FFFFFF` | 255 / 255 / 255 | 0 / 0 / 0 / 0 |

CMYK 为 RGB 公式近似值，未绑定 ICC 配置，不是印刷校样标准。Pantone 未指定；商业印刷需由印厂按纸张、油墨和实物色卡打样，不能直接承诺屏幕与成品完全一致。

- 淡蓝配白底对比度约 **1.85:1**，配深蓝约 **6.70:1**。白底淡蓝用于醒目的标志展示，不用于小号正文或操作提示。
- 在复杂照片上增加纯色衬底，或改用黑色/反白文件；不要加描边或阴影补救。
- `*-white.svg` 为光学反白版本：整组在原画布内微缩至 **98%**，减轻深底上浅色形状显得偏重的问题。直接使用文件，不再额外缩放其中的字母。

## 留白、尺寸与形态

- 安全留白：从可见轮廓向外至少保留一个主字干宽。主字标 `viewBox` 宽 1000 时，该单位约为 **30.72**；显示宽 250 px 时约 **7.7 px**。按比例缩放，不固定为某个像素值。
- 建议主字标至少 **240 px 宽**；独立图形至少 **16 px**，16–32 px 使用专用小尺寸版或深蓝底 favicon。更小位置不要硬塞完整英文名称。
- 小尺寸版仅调整独立图形的字腔与厚度，主字标、字距及短字尾不变。
- 不拉伸、旋转、拆字、改字距或调整组合比例；不添加渐变、阴影和立体效果。需要不同排布时，选择已有横排/竖排文件。
- 网站正文继续采用现有字体。此次标志定稿未指定新的整站字体或页面视觉系统。

## 官网与应用展示

- 当前生效字标：`../../public/images/site/pleiades-wordmark.svg`；配置在 `../../src/content/site/index.yaml` 的 `logo` 字段。Keystatic「站点设置」仍可更换 Logo。
- 网站图标为静态文件；manifest 使用普通浏览器展示模式，不添加安装脚本或服务工作线程。
- [应用展示 HTML](presentation/index.html) 与 [六种场景总览](presentation/slides/slide-04.png)；配置为 `presentation/spec.json`。展示画面仅演示使用方式，不代表已生产的实物或已发布的产品。
- 正式商标使用前仍需专业近似图形及商标检索；本设计交付不构成商标可注册性或印刷色彩认证。
